# PakJobs Daily – ASO listing v2 (2026-11-13)

Goal: rank for the searches Pakistani job seekers actually type on Play Store:
"govt jobs", "jobs in pakistan", "sarkari naukri", "pakistan jobs", "job alert", "ppsc", "nts", "fpsc", "naukri", "jobs app".
Play ranks mainly on **title > short description > full description (repeat main keywords 3–5 times, naturally)**, plus installs, ratings and retention.

Don't use "free", "best", "#1", "top", "new" in title/short description – Play flags promo words (it flagged Islam 365).
