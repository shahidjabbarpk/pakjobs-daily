Computer Operator, Data Entry Operator, Junior Clerk aur Assistant ki posts har hafte federal aur provincial mehkamon mein aati hain. In mein aksar written test ke baad ek typing ya computer skill test bhi hota hai – aur bohat se log isi mein reh jaate hain.

Skill test mein kya hota hai?

  • Typing speed: diya gaya paragraph muqarrara waqt mein type karna hota hai. Kitni speed (words per minute) chahiye, ye ad ya test schedule mein likha hota hai.
  • Accuracy: ghaltiyan bhi ginti hain – zyada ghaltiyon se speed achi hone ke bawajood fail ho sakte hain.
  • MS Office: kabhi Word mein letter format karna, Excel mein table ya SUM formula banana.
  • Urdu typing: kuch posts (khaas kar courts) mein – ad check karein.

30 din ka asaan plan

  1. Pehla hafta: seedha baithein, ungliyan home row (ASDF – JKL;) par, keyboard ki taraf dekhna band. Shuru mein speed kam hogi, ye normal hai.
  2. Doosra hafta: rozana 20–30 minute free typing tutor par – pehle accuracy.
  3. Teesra hafta: timed tests aur asli text (akhbar ke paragraph, official letter) type karein.
  4. Chautha hafta: exam jaisa time limit, aur ho sake to desktop keyboard par practice – test centre mein aksar desktop hota hai.

Test wale din

Jaldi pohanchein, chair aur keyboard set kar lein, ek ghalti par ghabrayein nahi – aaram se lagataar type karte rahein. CNIC, admit card aur call letter wale documents sath le jayein.

Passing criteria har mehkama ya testing body khud tay karti hai, is liye official ad ya call letter zaroor parhein.
